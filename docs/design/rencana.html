Langkah Pengerjaan Soal

(Sesuai Lembar Jawaban Ujian Praktikum)
/26
1

Langkah 1: Urutkan dari kebutuhan terbesar

Metode VLSM mewajibkan alokasi dari ruang yang paling banyak membutuhkan host.

1. Basis Data: 60 device 2. PPSI: 34 device 3. Dosen: 30 device 4. Seminar: 8 device 5. Server: 1 device

Hasil: Urutan alokasi blok dimulai dari Lab Basis Data (60) hingga Server (1).

/27
2

Langkah 2: Tentukan prefix tiap ruangan

Hitung bit host minimum menggunakan formula standar modul.

prefix = 32 − ceil(log2(host + 2))

• Lab Basis Data (60): 60 + 2 = 62 ≤ 2⁶ (64) → 32 - 6 = /26 (kapasitas 62 host)

• Lab PPSI (34): 34 + 2 = 36 ≤ 2⁶ (64) → 32 - 6 = /26 (kapasitas 62 host)

• Ruang Dosen (30): 30 + 2 = 32 ≤ 2⁵ (32) → 32 - 5 = /27 (kapasitas 30 host)

• Ruang Seminar (8): 8 + 2 = 10 ≤ 2⁴ (16) → 32 - 4 = /28 (kapasitas 14 host)

• Server (1): 1 + 2 = 3 ≤ 2² (4) → 32 - 2 = /30 (kapasitas 2 host)

Hasil: Dihasilkan 2 blok prefix /26, 1 blok /27, 1 blok /28, dan 1 blok /30.

/30
3

Langkah 3: Alokasikan blok berurutan

Subnet berikutnya selalu berlanjut tepat 1 angka setelah Broadcast Address (BA) sebelumnya.

# Subnet 1: Mulai 192.168.50.0/26 (Kelipatan 64) -> BA: 192.168.50.63

# Subnet 2: Mulai 192.168.50.64/26 (Kelipatan 64) -> BA: 192.168.50.127

# Subnet 3: Mulai 192.168.50.128/27 (Kelipatan 32) -> BA: 192.168.50.159

# Subnet 4: Mulai 192.168.50.160/28 (Kelipatan 16) -> BA: 192.168.50.175

# Subnet 5: Mulai 192.168.50.176/30 (Kelipatan 4) -> BA: 192.168.50.179

Hasil: Seluruh subnet tersusun rapi tanpa overlap; alamat bebas tersisa dari 192.168.50.180 hingga 192.168.50.255.

Kesimpulan Rencana IP

Alokasi VLSM untuk 5 ruangan dengan IP dasar 192.168.50.0/24 telah berhasil disusun dengan efisiensi tinggi, menghabiskan 180 alamat IP dan menyisakan 76 alamat IP (/256) untuk ekspansi jaringan masa depan.

Catatan: Pastikan interface router diatur manual jika opsi gateway diaktifkan pada topologi Cisco Packet Tracer.
