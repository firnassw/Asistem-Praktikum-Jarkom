Langkah Pengerjaan Soal (Format Lembar Jawaban)

5 Tahap Modul
1

Ubah IP dan Mask ke Bentuk Biner

Konversikan setiap oktet alamat IP dan subnet mask ke format 8-bit biner.

/27
Bit Jaringan (Network: 27 bit) Bit Host (Host: 5 bit)
IP (Host) :
11000000.10101000.00000000.000 00101 (192.168.0.5)
Mask (/27):
11111111.11111111.11111111.111 00000 (255.255.255.224)
check_circle Kesimpulan Langkah: Bit ke-1 sampai 27 adalah Network ID, sedangkan 5 bit terakhir adalah alokasi ruang Host ID.
2

Hitung Network Address: NA = IP AND Mask

Operasi logika Boolean AND menghasilkan nilai 1 hanya bila kedua bit bernilai 1.

AND
IP : 11000000.10101000.00000000.00000101 (192.168.0.5)
Mask : 11111111.11111111.11111111.11100000 (255.255.255.224)
------------------------------------------------- (Operasi Bitwise AND)
NA : 11000000.10101000.00000000.00000000 -> 192.168.0.0
verified Diperoleh Network Address (NA) = 192.168.0.0
3

Invers Subnet Mask (Wildcard Mask)

Membalikkan seluruh bit mask (NOT mask) untuk menentukan rentang broadcast.

NOT
Subnet Mask : 11111111.11111111.11111111.11100000 (255.255.255.224)
Invers Mask : 00000000.00000000.00000000.00011111 -> 0.0.0.31
functions Nilai wildcard mask adalah 0.0.0.31 (Ukuran blok subnet = 32 alamat).
4

Hitung Broadcast Address: BA = NA OR Invers Mask

Menggabungkan Network ID dengan seluruh Host bit bernilai 1.

OR
NA : 11000000.10101000.00000000.00000000 (192.168.0.0)
Invers Mask : 00000000.00000000.00000000.00011111 (0.0.0.31)
------------------------------------------------- (Operasi Bitwise OR)
BA : 11000000.10101000.00000000.00011111 -> 192.168.0.31
broadcast_on_personal Diperoleh Broadcast Address (BA) = 192.168.0.31
5

Karakteristik Subnetting (Subnet, Host, Blok)

Rumus dasar untuk ujian praktikum dan pembuatan tabel alokasi IP.

2^x
Jumlah Subnet
2x = 23 = 8

x = jumlah bit 1 pada oktet terakhir mask (3 bit).

Host Valid / Subnet
2y - 2 = 30

25 - 2 = 32 - 2 (y = 5 bit 0 pada host).

Ukuran Blok Subnet
256 - 224 = 32

Kelipatan: 0, 32, 64, 96, 128, 160, 192, 224.

Kesimpulan Subnetting

Alamat IP 192.168.0.5 dengan prefix /27 (netmask 255.255.255.224) berada di Subnet ke-1 dengan Network Address 192.168.0.0, Broadcast Address 192.168.0.31, dan rentang alamat host valid yang dapat dikonfigurasikan pada interface perangkat adalah 192.168.0.1 hingga 192.168.0.30 (total kapasitas 30 host).
