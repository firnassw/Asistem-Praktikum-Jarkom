Perangkat Modul Praktikum

Enam Alat Hitung Sesuai Modul Praktikum

Format lembar jawaban instan tanpa kalkulasi manual yang rawan keliru.
MODUL 01

Analisis subnet

Hitung NA, BA, subnet mask, dan tabel semua subnet dari satu IP.

192.168.0.5 /27 8 Subnet
MODUL 02

FLSM dan VLSM

Bagi jaringan induk ukuran tetap atau sesuai kebutuhan host.

192.168.64.0/24 64, 24, 8 host
MODUL 03

Rencana ruangan

Susun alokasi subnet otomatis dari dua digit NIM dan jumlah device.

NIM 50 -> 192.168.50.0/24 5 Lab
MODUL DASAR

Konversi basis

Ubah bilangan biner, oktal, desimal, dan heksa dengan tabel bit 128–1.

10101100 -> 172 0xAC
MODUL 04

Generator DHCP

Susun perintah CLI DHCP router dan prediksi IP klien pertama.

192.168.10.1/24 klien .6
INVENTARIS

Tabel IP perangkat

Rekap alamat IP, mask, gateway, dan DNS perangkat siap salin & cetak.

Server 192.168.1.1 /24 Ready
Metodologi Lembar Kerja

Format Seragam Seperti Lembar Jawaban Ujian

1
TAHAP 01

1. Isi Data Soal atau NIM

Masukkan alamat IP, jumlah ruangan dan device, atau dua digit terakhir NIM untuk menghasilkan IP Global otomatis.

Input: IP, Prefix, NIM Mahasiswa
2
TAHAP 02

2. Pelajari Langkah Biner & Rumus

Urutan pengerjaan mengikuti Modul 2, 3, dan 4: Diketahui, operasi biner AND/OR, penentuan prefix, hingga tabel alokasi.

Proses: Dekomposisi Bit & Kalkulasi
3
TAHAP 03

3. Salin ke Packet Tracer atau Cetak

Salin tabel alamat IP dan skrip perintah CLI router dua kolom langsung ke Cisco Packet Tracer atau cetak untuk laporan.

Output: Tabel Matriks & CLI Script
