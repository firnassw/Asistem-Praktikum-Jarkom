Peringatan Batasan FLSM (Alokasi Tetap Tidak Muat)

Induk 192.168.64.0/24 hanya memuat 2 subnet /25, padahal dibutuhkan 3 subnet.

Karena kebutuhan terbesar adalah 64 host (Lab Jaringan) yang mewajibkan prefix /25 (128 alamat/subnet), FLSM membagi network /24 menjadi prefix seragam /25 yang hanya menghasilkan 2 subnet (2(25-24) = 21 = 2). Subnet ke-3 tidak dapat dialokasikan tanpa memperbesar major network.

Urutkan Kebutuhan & Analisis Kebutuhan Terbesar

Metode VLSM memprioritaskan alokasi dari host terbanyak agar tidak terjadi fragmentasi blok.

Urutan Alokasi (Descending):

1. Lab Jaringan (64 host) → 2. Lab Komputasi (24 host) → 3. Lab Mulmed (8 host)

Catatan Perbandingan FLSM vs VLSM:

Pada FLSM, ukuran terbesar (64 host) memaksa semua subnet berukuran /25 sehingga network /24 hanya cukup untuk 2 subnet dan gagal memenuhi 3 lab praktikum.

Tentukan Prefix dan Ukuran Blok Masing-Masing Subnet

Rumus pemenuhan host: Kebutuhan + 2 (Network + Broadcast) ≤ 2H, dengan Prefix = 32 - H.

Lab Jaringan: 64 host + 2 = 66 ≤ 27 (128) → Prefix = 32 - 7 = /25 (Blok 128)
Lab Komputasi: 24 host + 2 = 26 ≤ 25 (32) → Prefix = 32 - 5 = /27 (Blok 32)
Lab Mulmed: 8 host + 2 = 10 ≤ 24 (16) → Prefix = 32 - 4 = /28 (Blok 16)

KESIMPULAN PERBANDINGAN FLSM VS VLSM

Alokasi FLSM dengan induk 192.168.64.0/24 tidak dapat memenuhi kebutuhan 3 ruangan karena ukuran subnet terbesar (/25) membatasi kapasitas maksimal menjadi hanya 2 subnet. Solusi yang tepat dan efisien adalah menggunakan VLSM, yang berhasil mengakomodasi seluruh 3 laboratorium dengan menghabiskan 176 alamat IP serta menyisakan 80 alamat IP bebas (192.168.64.176 – .255) untuk ekspansi jaringan mendatang.
