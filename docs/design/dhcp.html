Generator DHCP

Buat konfigurasi DHCP server router Cisco Packet Tracer secara otomatis dengan perintah CLI siap pakai.

Standar Cisco IOS 15.1+
settings_ethernet

Parameter Konfigurasi DHCP

IPv4 Router
Gateway

Alamat antarmuka router penghubung klien (LAN).

Netmask: 255.255.255.0 Network: 192.168.10.0
Bantuan cepat:
IP Awal
IP Akhir

IP statis untuk router, switch manajemen, dan printer lab.

device_hub
Hasil Alokasi Pertama

Klien pertama akan mendapat 192.168.10.6

(alamat .1 sampai .5 dikecualikan untuk router dan perangkat statis)

Subnet Pool 192.168.10.0/24
Rentang Dinamis .6 – .254 (249 Host)
Default Gateway 192.168.10.1
DNS Server 192.168.10.1
terminal

Cisco IOS CLI Script (Router Config)

Perintah CLI Cisco IOS Penjelasan Bahasa Indonesia
enable Masuk ke Privileged EXEC mode
configure terminal Masuk ke Global Configuration mode
interface fastEthernet0/0 Pilih interface penghubung LAN
ip address 192.168.10.1 255.255.255.0 Pasang alamat IP dan subnet mask gateway
no shutdown Aktifkan antarmuka agar menyala (link up)
exit Kembali ke konfigurasi global
ip dhcp pool dhcp_server Buat dan beri nama pool DHCP baru
network 192.168.10.0 255.255.255.0 Tentukan rentang subnet alamat IP pool
default-router 192.168.10.1 Tentukan alamat default gateway klien
dns-server 192.168.10.1 (Opsional) Alamat DNS server lokal
exit Selesai konfigurasi pool
ip dhcp excluded-address 192.168.10.1 192.168.10.5 Kecualikan alamat .1 s/d .5 dari pembagian DHCP
info Mengikuti contoh Modul 3; belum diuji di semua versi IOS.

Urutan Eksekusi Perangkat

01
Inisialisasi Antarmuka

Konfigurasi IP gateway fisik pada interface LAN dan eksekusi perintah no shutdown untuk menyalakan port.

02
Pembuatan Pool

Daftarkan tabel via ip dhcp pool lalu tentukan alamat jaringan beserta subnet mask gateway klien.

03
Eksklusi & Verifikasi

Amankan IP router dengan excluded-address, kemudian verifikasi via tab Desktop DHCP pada PC klien.

fact_check

Rangkuman Konfigurasi DHCP Server

Siap Salin

Konfigurasi DHCP pool 'dhcp_server' pada interface fastEthernet0/0 siap di-paste langsung ke tab CLI router Cisco Packet Tracer. PC/Laptop klien pertama yang diatur ke mode DHCP otomatis memperoleh alamat IP 192.168.10.6 dengan subnet mask 255.255.255.0 dan default gateway 192.168.10.1 tanpa bentrok dengan perangkat statis.
